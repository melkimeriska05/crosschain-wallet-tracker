# CrossChain Wallet Tracker

## Deskripsi
**CrossChain Wallet Tracker** adalah aplikasi web sederhana yang memungkinkan pengguna untuk memeriksa saldo dompet Ethereum dan Bitcoin mereka menggunakan API publik. Proyek ini bertujuan untuk memperkenalkan konsep interoperabilitas lintas rantai dan bagaimana pengembang dapat mengakses data dari berbagai blockchain.

## Fitur
- **Input wallet address**: Pengguna dapat memasukkan alamat Ethereum dan Bitcoin mereka.
- **Fetch saldo**: Menggunakan API publik untuk mengambil saldo dari alamat yang dimasukkan.
- **User Interface**: Menampilkan saldo Ethereum dan Bitcoin dengan antarmuka pengguna yang bersih dan sederhana.
- **Responsive**: Dibangun menggunakan React dan Tailwind CSS, aplikasi ini akan berfungsi dengan baik di perangkat desktop dan mobile.

## Teknologi
- **Frontend**: React.js
- **Styling**: Tailwind CSS
- **API**: Menggunakan API publik seperti Etherscan (untuk Ethereum) dan Blockchain.info (untuk Bitcoin)
